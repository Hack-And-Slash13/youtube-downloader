# Youtube-Downloader
Code that can download videos, audio, or livestreams from YouTube and convert them to different file types with yt-dlp and ffmpeg.

## Setup (yes, you have to set it up. Keep your pants on)

### Ffmpeg
Download ffmpeg and put the code in the bin subfolder of the ffmpeg folder (it must be in the same folder as ffmpeg.exe and ffmprobe.exe)

### yt-dlp

Open command prompt and type "pip install yt-dlp". Yes, it's that easy.
